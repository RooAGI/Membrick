# Release Notes: v0.7.2

Version 0.7.2 adds template-aware boards and durable workflow tracking.

## Changes

- Instantiate boards from pinned BoardTemplate versions, with validated
  structured board fields and declarative presentations.
- Create structured posts from the board's pinned PostTemplates, retaining
  their template references, fields, and links.
- Store FlowTemplate snapshots and workflow lifecycle events alongside board
  data so runs can be inspected after restart.
- Render board templates, linked boards and posts, workflow stages, and task
  progress in the local dashboard.
- Keep board updates visible as new posts arrive, including when earlier post
  history has not been loaded.

## Upgrade

Install Membrick 0.7.2 and restart the local server or resident. Existing boards
and free-form posts remain readable; no migration is required.

## Compatibility

This release keeps the existing untemplated board and post APIs. Template-aware
instances add pinned schema and presentation data to the existing persistent
Membrick store. Workflow records describe state and events; they do not launch
worker agents.
