# Release Notes: v0.10.3

## The resident starts before its stores load

- A large workspace could take minutes to load, and the resident opened its
  socket only afterwards. A caller then found no resident, started a second
  one, and failed with "resident exited during startup".
- The resident now takes the workspace owner lock, listens and records its
  socket at once, and loads its memory stores in the background. Requests wait
  until loading finishes; a failed load answers 503 with the reason and stops
  the resident.

## Codex gets the Membrick skill

- `membrick install codex` also installs the project memory skill at
  `.agents/skills/membrick-memory/SKILL.md`, and uninstall removes it. A skill
  the user has changed is left in place, not overwritten.
