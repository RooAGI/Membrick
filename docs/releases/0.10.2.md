# Release Notes: v0.10.2

## Search sees staged writes

- The first search after a write now publishes the pending writes before
  searching, so an add followed by a search returns the new memory at once.
  The publication is light (no checkpoint); idle searches skip it.

## Bare adds reuse one session

- Adds without an explicit session now reuse one stable default session per
  memory and user instead of minting a fresh session (and segment) per call.

## Faster publication

- Segment lexical indexes are kept in RAM and carried forward on pure
  additions, so publication no longer rebuilds the index from disk.

## MCP Registry

- Adds `server.json` for the Official MCP Registry listing
  (`io.github.RooAGI/membrick`) and the registry ownership line in the README.
