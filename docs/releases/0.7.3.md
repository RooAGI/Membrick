# Release Notes: v0.7.3

Version 0.7.3 is a maintenance release following the template-aware board and
workflow support introduced in v0.7.2.

## Changes

- The Membrick update action now tells users to fully quit and reopen Codex,
  Claude, or AGY so the client reconnects with the updated installation.
- Pull request checks for the Node binding use one Linux target. The release
  workflow continues to build the supported platform packages.
- The Quickstart now explains how to update existing Membrick installations
  across the supported package managers and standalone downloads.
- Renamed the internal Rust code review module file to `code_review.rs`; this
  does not change the public API.

## Upgrade

Install Membrick 0.7.3 and restart the agent client after updating. Existing
boards, posts, and workflow records remain compatible; no data migration is
required.
