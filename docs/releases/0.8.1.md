# Release Notes: v0.8.1

Version 0.8.1 adds opt-in telemetry for Membrick installations.

## Changes

- Shell and PowerShell installers can report a successful installation after
  asking for consent.
- Cargo, PyPI, and npm installs ask on first interactive CLI use. Release builds
  run from Cargo's `target/release` directory are reported as `cargo_build`.
- Reports include a random install ID and basic platform and installer details.
  They exclude names, email addresses, project paths, and memory data.

## Upgrade

Install Membrick 0.8.1 and restart the agent client after updating. Telemetry is
opt-in and does not affect local memory data. The license service must be
updated separately to accept Cargo, pip, npm, and source-built release events.
