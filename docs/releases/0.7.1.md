# Release Notes: v0.7.1

Version 0.7.1 adds the global project manager setup and fixes the feature-gated
build path for the new manager commands.

## Changes

- Running `membrick` without arguments sets up the global project manager MCP
  for supported agent clients and displays the available CLI commands.
- Track installed projects in the local project registry.
- Keep provider-specific project setup in Codex, Claude Code, and AGY.
- Update locked TLS dependencies to versions that address current RustSec
  advisories.

## Upgrade

Install Membrick 0.7.1 and run `membrick` to set up or refresh the global
project manager MCP. Existing per-project installations remain available.

## Compatibility

This is a patch release. It does not change the on-disk memory format.
