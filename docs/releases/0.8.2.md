# Release Notes: v0.8.2

Version 0.8.2 stops memory retrieval on tool hooks.

## Changes

- Pre-tool and post-tool hooks no longer retrieve memory for Claude Code,
  Codex, Gemini CLI, and AGY. They still record hook telemetry.
- Memory is still retrieved at session start, on each prompt, and at subagent
  start.
- Tool calls and results are still stored in memory when a turn ends, as before.

## Upgrade

Install Membrick 0.8.2 and restart the agent client after updating. This is a
patch release. It does not change the on-disk memory format.
